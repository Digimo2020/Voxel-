# Voxel brand v2

Minimal waveform identity: three rounded bars, one blue accent, no gradients, no microphone.

| File | Use |
| :--- | :--- |
| `voxel-mark-a.svg` / `-white.svg` | Mark only (monochrome, light / dark backgrounds) |
| `voxel-app-icon-a.svg` / `-dark.svg` | App icon (rounded square) |
| `voxel-bubble-a.svg`, `voxel-bubble-doc.svg` | Floating bubble icons |
| `*-b.svg` | Alternative "V-wave" mark (not used) |

Accent: `#3478F6` (light) · `#6B9FFF` (dark). Regenerate everything with `python scripts/generate_brand_v2.py --apply A`.
Icons in the UI are [Lucide](https://lucide.dev) outline icons (ISC licence).
